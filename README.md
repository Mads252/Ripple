# Ripple

A social media web app built with PHP and MySQL — school project at Zealand (Multimedia Design).

## Features

- User registration and login
- Create, edit and delete posts
- Like posts
- User profiles with profile settings
- Follow system

## Tech Stack

- **Backend:** PHP (OOP)
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript

## Getting Started

1. Import `madstofteriksen_dk_db_ripple.sql` into your MySQL database via phpMyAdmin
2. Update `includes/` with your database credentials
3. Run on a local PHP server (e.g. XAMPP)
